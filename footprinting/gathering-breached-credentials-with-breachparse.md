# Gathering Breached Credentials with BreachParse

[https://github.com/Byte-Capsule-Ltd/breach-parse](https://github.com/Byte-Capsule-Ltd/breach-parse)\
Download breached password list from the torrent. then move it to the opt folder with it add the breach-parse.sh file and give full permission. the run "./breach-parse.sh @tesla.com tesla.txt" and wait. it will show the email, passwords.&#x20;
