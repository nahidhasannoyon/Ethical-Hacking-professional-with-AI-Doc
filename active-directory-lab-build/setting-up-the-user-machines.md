# Setting Up the User Machines

## **Windows 10 Enterprise Setup Guide**

### **1. Setup in VirtualBox:**

#### ✅ **Step 1:** Create a New Virtual Machine

1. Open **VirtualBox**.
2. Create a new Virtual Machine for **Windows 10 Enterprise**.
3. Set the following specifications:
   * **OS Type:** Windows 10 (64-bit)
   * **Minimum Disk:** 50 GB
   * **Memory:** At least **4 GB**
   * **ISO/VHD:** Use a valid Windows 10 Enterprise ISO or VHD.

***

#### ✅ **Step 2:** Configure Network

1. Go to **Settings** → **Network**.
2. Set **Adapter 1** to **Bridged Adapter** (to enable network access).

***

#### ✅ **Step 3:** Install Windows 10

1. Start the VM.
2. Follow the on-screen instructions to install Windows 10.
3. Set up a **strong password** for the administrator account.

***

#### ✅ **Step 4:** Rename Computer

1. Open **Settings** → **System** → **About** → **Rename this PC**.
2. Set a **memorable name** (e.g., `Client-PC`).
3. Restart the computer if prompted.

***

### **✅ Setup Complete!**

🎯 Your Windows 10 Enterprise setup is now complete and ready for domain joining or further configuration!
