# Joining Our Machines to the Domain

Start Windows Server 2019 and check the IP address using ipconfig.

start the widows 10 enterprise and create a new folder named "Shared Folder" and right click choose properties then sharing tab and click share and share in bottom and choose "Yes, turn on network Discovery ..." done.&#x20;

In wifi icon right click and choose "Open Network & Internet Sharing" and chose "Change adapter options", right click on the Ethernet and choose properties and double click on the IPV4 option. choose "Use the following DNS server address and set the Windows Server 2019's IP.&#x20;

Open Properties from This PC and click "Change Settings" and click on Change and enter the Domain name and also using the Administrator name and password and reboot.&#x20;

Now in Windows Server 2019 open Active Directory Users and Computers and click domain name and computers and check if the windows 10 name is there or not.&#x20;
