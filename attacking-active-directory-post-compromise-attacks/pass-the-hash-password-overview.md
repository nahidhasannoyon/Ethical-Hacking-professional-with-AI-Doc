# Pass the Hash / Password Overview

**Pass-the-Hash আক্রমণ কী?**&#x20;

Pass-the-Hash আক্রমণ হলো এমন একটি হ্যাকিং টেকনিক, যেখানে আক্রমণকারী কোনো ব্যবহারকারীর পাসওয়ার্ড জানার দরকার হয় না। তার পরিবর্তে, তারা পাসওয়ার্ডের হ্যাশ (hash) ব্যবহার করে সরাসরি সেই ইউজারের অ্যাকাউন্টে ঢুকে যেতে পারে।&#x20;

#### **Hash মানে কী?**&#x20;

হ্যাশ হলো পাসওয়ার্ডের এনক্রিপ্টেড বা বিশেষভাবে পরিবর্তিত রূপ। Active Directory (AD)-তে যখন কোনো ইউজার লগইন করে, তখন পাসওয়ার্ডের বদলে এই হ্যাশ ব্যবহার করে অথেন্টিকেশন করা হয়।&#x20;

#### **Pass-the-Hash কীভাবে কাজ করে?**&#x20;

আক্রমণকারী প্রথমে কোনোভাবে একটি কম্পিউটার বা সার্ভার থেকে ইউজারের হ্যাশ চুরি করে। এরপর সেই হ্যাশ ব্যবহার করে আক্রমণকারী অন্য কোনো সার্ভারে লগইন করে, যেটা সেই হ্যাশ গ্রহণ করে। এইভাবে, আসল পাসওয়ার্ড জানার প্রয়োজন ছাড়াই, শুধু হ্যাশ ব্যবহার করেই সিস্টেমে ঢুকে পড়া যায়।&#x20;

#### Active Directory-তে কেন এটা সম্ভব?&#x20;

Active Directory-তে অনেক সময় NTLM (NT LAN Manager) বা Kerberos Authentication ব্যবহার করা হয়, যেখানে পাসওয়ার্ডের বদলে হ্যাশ পাস করা হয়। যদি কোনো অ্যাটাকার সেই হ্যাশ পেয়ে যায়, তবে সে ঐ ইউজারের মতো করে লগইন করতে পারে, পাসওয়ার্ড ছাড়াই।&#x20;

**উদাহরণ** - ধরুন, একজন অ্যাডমিন কোনো সার্ভারে লগইন করেছে। হ্যাকার মেমরি থেকে সেই অ্যাডমিনের NTLM হ্যাশ চুরি করল। এরপর সেই হ্যাশ ব্যবহার করে হ্যাকার অন্য সার্ভারে সেই অ্যাডমিন হিসাবে লগইন করে ফেলল। এতে অ্যাডমিন পাসওয়ার্ডের দরকার পড়ল না, শুধু হ্যাশ দিয়েই কাজ হয়ে গেল। Pass-the-Hash প্রতিরোধের কিছু উপায় Privileged Account আলাদা রাখা (Tiered Admin Model) Credential Guard চালু করা (Windows 10/11 & Server 2016+) NTLM ব্যবহার কমানো Regular Credential Cleanup (LSASS থেকে credentials মুছে ফেলা) Multi-Factor Authentication (MFA) ব্যবহার করা |

**সংক্ষেপে -** Pass-the-Hash মানে হলো, ইউজারের পাসওয়ার্ড না জেনে, শুধুমাত্র পাসওয়ার্ডের হ্যাশ ব্যবহার করে সরাসরি Active Directory বা অন্য সিস্টেমে লগইন করার আক্রমণের কৌশল।
