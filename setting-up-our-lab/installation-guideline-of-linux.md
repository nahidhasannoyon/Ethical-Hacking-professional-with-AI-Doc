# Installation Guideline of Linux

## You can Setup the Lab in your PC (Desktop / Laptop). Instructions for PC User:

* Desktop or Laptop both can be used.&#x20;
* Minimum 4 GB Ram ( For Basic Practice and Exploitation Development ) Recommending 8 GB Ram, Core 13 Processor / Ryzen 5 Processor, 2 GB GPU.
* You can use SSD (Recommending 256 GB) or HDD (Recommending 1 TB )
* To Set Up Hacking Lab - Kali Linux / Parrot OS, Windows 7 - Windows 10 can be recommended.&#x20;
* You can set up Lab on Virtual Box / Vmware / Bootable Pendrive.
* If you use Pendrive to setup lab, minimum 16 GB is Recommending.&#x20;
* Install Linux - Process - Run

{% hint style="info" %}
Refer to various YouTube tutorials for installing operating systems in Virtual Box, VMware, or via a bootable pendrive. Ensure you choose videos that demonstrate the installation of the latest OS versions for up-to-date guidance.
{% endhint %}
