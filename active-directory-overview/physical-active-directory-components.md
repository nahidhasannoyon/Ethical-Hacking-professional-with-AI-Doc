# Physical Active Directory Components

What is Physical Active Directory and its Components?

**Physical AD (ফিজিক্যাল AD)** Physical AD বলতে Active Directory পরিচালনার জন্য প্রয়োজনীয় বাস্তব নেটওয়ার্ক অবকাঠামো বোঝায়। এটি মূলত AD-র কার্যক্রমকে সমর্থন করে এমন শারীরিক উপাদানগুলোকে নির্দেশ করে। উপাদানসমূহ:&#x20;

Domain Controller (DC): এটি একটি সার্ভার, যেখানে Active Directory-এর ডেটাবেস সংরক্ষণ এবং পরিচালনা করা হয়। Sites: নেটওয়ার্কের বিভিন্ন শারীরিক অবস্থানকে উপস্থাপন করে। একটি সাইট সাধারণত এক বা একাধিক IP সাবনেট দ্বারা সংজ্ঞায়িত হয়। Replication: ডোমেইন কন্ট্রোলারগুলোর মধ্যে ডেটা সিঙ্ক্রোনাইজ করার প্রক্রিয়া। Intra-Site Replication: এক সাইটের ভেতরে দ্রুত এবং ঘন ঘন হয়। Inter-Site Replication: বিভিন্ন সাইটের মধ্যে কম ফ্রিকোয়েন্সিতে হয়, যাতে ব্যান্ডউইথের অপচয় কম হয়। উদ্দেশ্য: ডোমেইন কন্ট্রোলারগুলোর মধ্যে ডেটার কার্যকরী রেপ্লিকেশন নিশ্চিত করা। নেটওয়ার্কের অবস্থানের ওপর ভিত্তি করে পারফরম্যান্স অপ্টিমাইজ করা। বৃহৎ ও ভৌগোলিকভাবে বিচ্ছিন্ন নেটওয়ার্কে লেটেন্সি ও ব্যান্ডউইথ ব্যবহারের ক্ষেত্রে দক্ষতা বাড়ানো।
